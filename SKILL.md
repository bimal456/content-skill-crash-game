# Crash Games and Game Shows: SEO Content Skill

## Mission
Create accurate, original, human-sounding, search-focused informational websites for individual games. Distinguish **crash games** (Aviator), **tower-style multiplier games** (Tower Rush, confirm exact title/provider), and **live wheel game shows** (Evolution Ice Fishing). Never transpose game mechanics from one title to another.

## Mandatory inputs
- Domain, page URL or planned page type; exact game title and official developer/provider.
- Target country, language, primary keyword, secondary keywords and requested word count.
- Existing pages to avoid cannibalisation. If missing, research site and declare assumptions.

## Phase 1: classify and verify the game
1. Match exact game to the developer's official game listing and official rules. Avoid confusing unrelated games with the same name (e.g. Tower Rush tower defence vs multiplier game).
2. Record: title, developer, category, core loop, stages/rounds, features, RTP by version/bet, max multiplier, demo availability, mobile support, randomness/fairness, latest verification date and primary source.
3. Treat all figures as unverified until supported by a primary source. If no source, omit the figure or label as unverified. Never imply all bets share the same RTP.
4. Do not invent casino licences, trial sessions, player reviews, live data, payout speed, bonuses, apps, APKs, game screenshots or results.
5. Do not call an informational fan site the game's official producer or game operator.

## Phase 2: site planning
- Audit current page taxonomy, indexable URLs, intent, overlap, metadata, internal links and outdated claims.
- Map ONE distinct primary intent and keyword per page.
- Standard informational topical cluster, include only when supported by the title: homepage/game overview; how it works; rules; RTP and probabilities; multipliers or bonus features; free/demo status; mobile/desktop; randomness and provably fair (only if documented); history/results (only real, dated verifiable data); legitimate game vs imitation; risks and limits; FAQ.
- Optional comparative pages must provide genuine side-by-side differences, not doorway pages.
- Keep evergreen informational topics distinct from time-sensitive 'today', news and active offers.

## Phase 3: research workflow
Use the game's official developer page, downloadable rules and reputable regulator/standards sources first. Check independent informational coverage for missed questions, not facts by default. Capture source URL and accessed date for each changeable claim. Competitor review: current top-ranking pages, title/H1 structure, question coverage, confusing claims, unanswered questions, citation gaps and missing risk explanations. Do not copy phrases or headings wholesale.

## Phase 4: page writing
- Start with a direct answer in 2-4 sentences. No generic introductions, hype or invented testing credentials.
- H1 contains the primary topic; H2s reflect discrete user questions; H3s only when structurally needed.
- Use short purposeful paragraphs, technical examples and a table only for real comparisons or numeric data.
- Keep word count commensurate with intent; user-provided counts are targets, not permission for filler.
- Separate documented facts, calculated examples and conditional features by operator/version.
- Describe losses, variance, house edge and inability to reliably predict independent outcomes alongside positive features.
- Never market betting as a way to earn income or recover losses. Do not provide winning systems or fabricated prediction signals.
- Avoid em dashes and phrases such as 'Explore', 'Discover', 'Unlock', 'Dive into', 'ultimate experience', and boilerplate 'In today's digital world'. No forced listicles.
- Use natural English, Dutch or Hindi/Hinglish as requested. Translate intent, not word for word. Keep exact on-screen game labels unchanged.

## SEO rules
- Primary keyword in H1, title and first paragraph when natural; secondary terms only when relevant.
- Distinct metadata on each page. If the user requests 55-60 character titles and 155-160 character descriptions, count characters; do not claim search engines enforce those limits.
- No keyword stuffing, fake freshness dates or meaningless '2026' updates.
- Use contextual internal links only to real live URLs. Never invent paths. Ensure glossary, FAQ and similar content does not duplicate target pages.
- Suggest appropriate Article/FAQ structured data only where content and current search engine eligibility permit; never fabricate reviews or ratings.

## Compliance and editorial safety
- Check jurisdiction and the current laws before drafting country-facing material; the legal status of online money gaming can change.
- India-facing content must not promote or facilitate prohibited real-money online gambling, including registration, deposits, offshore workarounds, ads and payment instructions. Prioritise educational explanations of mechanics and risks.
- No claims that offshore licensing equals legality in the reader's country.
- Explain RTP is a statistical long-run metric, not an individual-session payout promise; stake losses are possible.
- Disclose affiliate relationships if any, and do not pretend to have direct gameplay experience.
- Provide age-appropriate safety language and signpost locally relevant help where applicable.

## Game-specific routing
See `references/game-profiles.md`; do not re-use one game's figures for another. Always re-verify game/version facts before publication.

## Content quality gate
Before delivering:
1. Every specific numerical/game-mechanics claim traceable to primary documentation or clearly identified as a calculation.
2. Core search question answered in first section and throughout.
3. Each section unique and useful; no recycled introduction or conclusion.
4. No unauthorised real-money funnel, misleading results or fake demo.
5. Correct language, heading order, spelling and requested character/word counts.
6. Links valid, internal anchors natural, no invented URL.
7. Explain downside and uncertainty, not promotional-only benefits.
8. Note what was checked, sources and unresolved uncertainty.

## Output format
Return (a) target keyword/intent and page type, (b) meta title + character count, (c) meta description + character count, (d) unique H1 and complete publishable copy, (e) relevant FAQ and internal-link suggestions only if required, and (f) concise verification and compliance notes.
